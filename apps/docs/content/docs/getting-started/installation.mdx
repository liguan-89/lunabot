## Download a released build

Choose your computer below. Each link always downloads the latest published build.

| Platform | Recommended package | Notes |
|---|---|---|
| macOS Apple silicon | [Download `.dmg`](https://github.com/liguan-89/lunabot/releases/latest/download/LUNABOT.dmg) | Signed and notarized. Drag to Applications. |
| macOS Intel | Not published yet | Build from source below, or run the Apple silicon build on macOS 14+ with Rosetta if it suits your plugins. |
| Windows x64 | [Download installer](https://github.com/liguan-89/lunabot/releases/latest/download/LUNABOT-setup.exe) | Per-user installer; Windows signing is not yet available. |
| Ubuntu 24.04 x64 | [Download `.deb`](https://github.com/liguan-89/lunabot/releases/latest/download/LUNABOT-amd64.deb) · [AppImage](https://github.com/liguan-89/lunabot/releases/latest/download/LUNABOT.AppImage) | The `.deb` is recommended; the AppImage is portable. |
| Fedora x64 | [Download `.rpm`](https://github.com/liguan-89/lunabot/releases/latest/download/LUNABOT-x86_64.rpm) | Community-supported; install with `sudo dnf install ./LUNABOT-x86_64.rpm`. |

<Callout type="warn" title="Windows SmartScreen">
  The Windows installer is not code-signed yet. Windows may show “Unknown publisher.” Verify that you downloaded it from the official Luna Bot releases repository before choosing **More info → Run anyway**.
</Callout>

<Callout title="Windows install folder">
  By default the Windows app installs to `%LOCALAPPDATA%\Programs\LunaBot`, and every update goes back to the folder the installer recorded. Keep it where the installer put it: a copy moved by hand (for example from C: to D:) is left behind, and the next update lands in the recorded folder again.
</Callout>

## Install an agent CLI

Luna Bot needs at least one supported agent engine installed and signed in. Claude and Codex are the most common starting points.

1. Install the CLI from its official provider.
2. Run it once in a terminal and complete sign-in.
3. Restart Luna Bot.
4. Open the model picker. Available engines appear normally; unavailable engines explain what is missing.

See [Agent engines](../providers/index.mdx) for the complete list and explicit path overrides.

## Using Luna Bot at work

If your company uses Luna Bot Admin, you can sign in with your organization to use the AI models it provides, alongside your own. It is optional. See [Use Luna Bot at work](./organisation.mdx).

## Build from source

Requirements: Node.js 24 or newer, pnpm 10.33.0, and at least one authenticated agent CLI.

```bash
git clone https://github.com/liguan-89/lunabot.git
cd lunabot
corepack enable
pnpm install --frozen-lockfile
```

Run the harness, web UI, and Electron shell in separate terminals:

```bash
pnpm dev:server
pnpm dev
pnpm dev:desktop
```

## Where data lives

Luna Bot stores its application data under `~/.lunabot`. Electron window and browser data use the normal per-platform application data directory.
