2026-11-26。半成品排查批次 5a：服务端 API 已放行/存在但 Android 未接的六项。

## 本轮实施（PR 一）

### ③ 限额 reset 后继续（小）
- 失败卡（消息带 `tool.limitResetsAt`，SSE 已透传）上加「到点继续」按钮 →
  `POST /api/limit-resets/continue {botId,threadId}`（已放行；201 幂等，重复点返回已有 routine）。
- 不做用量条展示（要加白名单+轮询，留给后续）。
- 降级：旧电脑 404 → 静默不显示按钮（先例：refreshConnectionMetadata 静默缺席）。

### ④ activity + MCP 只读页（中小）
- activity：`GET /api/bots/:id/activity?limit=` 已放行 → 行列表只读页。
- MCP：core 已有 `mcpServers()`+`McpServersCard` 半成品，补独立只读页与入口。
- 入口：BotOverviewScreen 的 OverviewActionRow（per-bot 只读页既有先例位）。
- 新页骨架照 `ConnectedAppsScreen` 加载/刷新/错误三态；导航照 Navigation.kt+RootScreen 惯例。
- null=拒答画一行「电脑拒答」，非错误横幅（loadMcpServers 先例）。

## 明确不做（本轮）

- **①团队记忆**：CRUD 全量+revision 冲突+入口设计未定（Android 无团队地图页），只读版也至少中小，待入口拍板。
- **⑥PHONE_RESPOND_TO_INVITE**：代码增量中小，但「是否真发回执取决于 sync adapter」需真机矩阵验证，单列。
- **⑥PHONE_FIND_PLACES_NEARBY**：无数据源——app 刻意不用 GMS、工具纪律不联网，引 Places SDK 或网络 API 都是设计级决策，先拍板再动工。
- **⑤凭据卡 HPKE**：字节级兼容（base64url 无填充/65 字节未压缩点/AAD 八字段）+已配对设备需重配对或 TOFU 补 pin，独立大线。
